سیستم نظرات و امتیازدهی چندمعیاره با قالب‌های متعدد، نقاط قوت و ضعف، رأی مفید بودن، پاسخ مدیر و پنل تنظیمات با پیش‌نمایش زنده.

== Description ==

OmoReviews یک افزونه نظرات حرفه‌ای است که مخصوص سایت‌های دایرکتوری مشاغل طراحی شده اما روی هر نوع محتوایی کار می‌کند.

ویژگی‌ها:

* امتیازدهی چندمعیاره (کیفیت، قیمت، برخورد پرسنل و معیارهای دلخواه)
* شش قالب نمایش: کارت‌ها، کلاسیک، تایم‌لاین، فشرده، مجله‌ای، شبکه‌ای
* نوار خلاصه امتیاز با توزیع ستاره‌ها و میانگین معیارها
* ثبت نقاط قوت و ضعف برای هر نظر
* گزینه «این کسب‌وکار را توصیه می‌کنم»
* رأی مفید بودن نظر (بله / خیر)
* پاسخ کاربران و مدیر به نظرات (سلسله‌مراتب یک‌سطحی)
* داده ساختاریافته Schema.org (JSON-LD) برای نمایش ستاره در نتایج گوگل
* غیرفعال‌سازی اختیاری کامنت پیش‌فرض وردپرس
* شخصی‌سازی کامل متن‌ها و استایل (رنگ، فاصله، اندازه)
* پنل تنظیمات با پیش‌نمایش زنده
* تأیید نظرات (مدیریت)، محافظت ضد اسپم، محدودیت زمانی ارسال
* مرتب‌سازی و بارگذاری بیشتر بدون رفرش صفحه
* راست‌چین و کاملاً ریسپانسیو
* پشتیبانی از تاریخ شمسی (در صورت وجود تابع jdate)

== Installation ==

1. پوشه افزونه را در wp-content/plugins قرار دهید.
2. از منوی افزونه‌ها فعال کنید.
3. به «نظرات (OmoReviews) → تنظیمات» بروید و نوع محتوای مورد نظر را فعال کنید.
4. نظرات به‌صورت خودکار زیر محتوا نمایش داده می‌شوند، یا از شورت‌کد [omo_reviews] استفاده کنید.
