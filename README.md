# امو ریویوز (OmoReviews)

![OmoReviews](.github/assets/cover.jpg)

**سیستم حرفه‌ای نظرات و امتیازدهی چندمعیاره برای وردپرس و ووکامرس** — کاملاً فارسی، راست‌چین و با تاریخ شمسی.

امو ریویوز بخش نظرات سایت را به یک سامانهٔ کامل امتیازدهی تبدیل می‌کند: کاربر هر جنبه را جداگانه امتیاز می‌دهد، نقاط قوت و ضعف را می‌نویسد، کسب‌وکار یا محصول را به دیگران پیشنهاد می‌کند، و خریدار واقعی با نشان «کاربر تأییدشده» از بقیه متمایز می‌شود. ستاره‌های امتیاز هم با دادهٔ ساختاریافتهٔ استاندارد در نتایج گوگل نمایش داده می‌شوند.

> این ریپو نسخهٔ متن‌باز و کامل افزونه است و هیچ قفل یا بررسی لایسنسی ندارد. همهٔ امکانات بدون محدودیت فعال‌اند.

## امکانات

**اعتمادسازی**
- نشان «کاربر تأییدشده» کنار نظر خریداران واقعی
- تشخیص خودکار خریدار محصول در ووکامرس، و تأیید دستی مدیر برای سایت‌های دیگر
- گزینهٔ پیشنهاد خرید و نمایش درصد کاربرانی که پیشنهاد کرده‌اند
- پاسخ مدیر یا صاحب کسب‌وکار زیر هر نظر، با برچسب جدا

**تجربهٔ کاربر**
- امتیازدهی چندمعیاره (معیارها را خودتان تعریف می‌کنید) یا تک‌معیاره
- ثبت نقاط قوت و ضعف به‌صورت جداگانه
- رأی «مفید بود / نبود» و مرتب‌سازی بر اساس سودمندی
- گفتگوی یک‌سطحی کاربران زیر هر نظر
- ۶ قالب نمایش: کارت، کلاسیک، تایم‌لاین، فشرده، مجله‌ای، شبکه‌ای
- بارگذاری بیشتر نظرات بدون رفرش صفحه
- ریسپانسیو و مناسب لمس روی موبایل

**مدیریت و سئو**
- دادهٔ ساختاریافتهٔ Schema.org (JSON-LD و Microdata) برای نمایش ستاره در گوگل
- پنل تنظیمات تب‌بندی‌شده با پیش‌نمایش زنده
- تنظیمات اختصاصی برای هر نوع محتوا (مثلاً پنهان‌کردن معیار قیمت در مقاله‌ها)
- شخصی‌سازی همهٔ متن‌ها، رنگ‌ها، فاصله‌ها، فونت گوگل یا فونت آپلودی، و CSS دلخواه
- ضد اسپم با هانی‌پات و محدودیت زمانی بین ارسال‌ها
- تأیید نظرات پیش از نمایش، یا تأیید خودکار برای کاربران وارد‌شده
- لینک ورود سفارشی با پشتیبانی از placeholder `{redirect}`
- غیرفعال‌سازی کامنت پیش‌فرض وردپرس روی نوع‌های فعال
- ذخیرهٔ نظرات در جدول اختصاصی، مستقل از کامنت‌های وردپرس

## نصب

**از طریق پیشخوان وردپرس**

1. از بالای همین صفحه روی **Code ← Download ZIP** کلیک کنید (یا از بخش Releases فایل zip را بگیرید).
2. در پیشخوان وردپرس به **افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه** بروید.
3. فایل zip را انتخاب کرده و **هم‌اکنون نصب کن** را بزنید، سپس افزونه را **فعال** کنید.

> اگر فایل را از Download ZIP گیت‌هاب گرفته‌اید، نام پوشهٔ داخلش شبیه `omoreviews-main` است. این مشکلی ایجاد نمی‌کند، ولی اگر بخواهید می‌توانید قبل از نصب نامش را به `biz-reviews` تغییر دهید.

**از طریق گیت**

```bash
cd wp-content/plugins
git clone https://github.com/Hoseinkhalaj1/OmoReviews.git biz-reviews
```

سپس افزونه را از پیشخوان فعال کنید. با فعال‌سازی، جدول‌های `{prefix}bizrev_reviews` و `{prefix}bizrev_votes` ساخته می‌شوند.

## راه‌اندازی

پس از فعال‌سازی، منوی **OmoReviews** در پیشخوان ظاهر می‌شود. تنظیمات در پنج تب مرتب شده‌اند و تغییرات در پیش‌نمایش کنار پنل همان لحظه دیده می‌شوند.

| تب | چه چیزی تنظیم می‌شود |
|---|---|
| **عمومی** | نوع‌های محتوای فعال، قالب نمایش، راست‌چین، فونت |
| **امتیاز و فرم** | حالت تک/چندمعیاره، تعریف معیارها، حداکثر ستاره، امکانات فرم، تأیید هویت خریدار، نمایش، تنظیمات اختصاصی هر نوع محتوا، لینک ورود |
| **متن‌ها** | همهٔ متن‌های فرم، دکمه‌ها، پیام‌ها و خطاها |
| **استایل** | رنگ‌ها، فاصله‌ها و اندازه‌های هر بخش |
| **پیشرفته** | دادهٔ ساختاریافته و نوع آن، غیرفعال‌سازی کامنت وردپرس، CSS سفارشی |

مدیریت نظرات از **OmoReviews ← مدیریت نظرات** انجام می‌شود: تأیید، بازگردانی به انتظار، اسپم، حذف، پاسخ، و تأیید یا لغو تأیید خریدار. پاسخ‌های هر نظر هم زیر همان نظر با امکان تأیید و حذف نمایش داده می‌شوند.

## نمایش نظرات و شورت‌کدها

روی نوع‌های محتوایی که در تنظیمات فعال کرده‌اید، بلوک نظرات به‌صورت خودکار زیر محتوا نمایش داده می‌شود. برای قرار دادن در جای دلخواه از شورت‌کدها استفاده کنید:

| شورت‌کد | خروجی |
|---|---|
| `[omo_reviews]` | بلوک کامل نظرات (خلاصهٔ امتیاز، فرم و لیست) |
| `[omo_rating]` | نشان خلاصهٔ امتیاز (میانگین، ستاره و تعداد) |
| `[omo_average]` | فقط عدد میانگین امتیاز |
| `[omo_count]` | فقط تعداد نظرات |
| `[biz_reviews]` | معادل `[omo_reviews]`، برای سازگاری با نسخه‌های قبلی |

همهٔ شورت‌کدها پارامتر اختیاری `id` می‌گیرند. بدون آن، پست جاری استفاده می‌شود.

```text
[omo_reviews id="123"]
[omo_rating id="123" count="0"]
```

`[omo_rating]` سه پارامتر `stars`، `average` و `count` (مقدار `0` یا `1`) هم دارد تا هر بخش را جداگانه نمایش دهید یا پنهان کنید.

**المنتور و صفحه‌سازها:** ویجت **Shortcode** را در صفحه قرار دهید و شورت‌کد را داخلش بنویسید. همین روش در بلوک شورت‌کد گوتنبرگ و سایر صفحه‌سازها هم کار می‌کند.

## نشان کاربر تأییدشده

این قابلیت از **تب امتیاز و فرم ← تأیید هویت خریدار** فعال می‌شود و دو روش دارد:

- **خودکار (ووکامرس):** اگر ووکامرس نصب باشد و نظر روی یک محصول ثبت شود، افزونه با `wc_customer_bought_product()` بررسی می‌کند که نویسنده (با شناسهٔ کاربر یا ایمیل) آن محصول را خریده یا نه. در صورت خرید، نظر به‌طور خودکار تأییدشده علامت می‌خورد. روی سایت بدون ووکامرس این بخش هیچ اثری ندارد.
- **دستی:** در صفحهٔ مدیریت نظرات، دکمهٔ **تأیید خریدار** کنار هر نظر اصلی قرار دارد. برای سایت‌های بدون ووکامرس یا خریدهای خارج از سایت از این روش استفاده کنید.

متن و رنگ نشان از تب‌های **متن‌ها** و **استایل** قابل تغییر است.

## سئو و دادهٔ ساختاریافته

وقتی دادهٔ ساختاریافته در تب **پیشرفته** فعال باشد، افزونه برای هر صفحه‌ای که نظر دارد این خروجی‌ها را تولید می‌کند:

- **JSON-LD** شامل `aggregateRating` (میانگین و تعداد نظرات) و چند نظر اخیر
- **Microdata** روی هر نظر (`Review`، `Person`، `Rating`)

نوع آیتم اصلی را می‌توانید `Product`، `LocalBusiness` یا `Service` انتخاب کنید. JSON-LD مستقل از بارگذاری AJAX در HTML اولیهٔ صفحه قرار می‌گیرد تا موتور جستجو آن را ببیند.

> اگر افزونهٔ سئوی دیگری (مثل Rank Math یا Yoast) هم برای همان صفحه `aggregateRating` تولید می‌کند، یکی از آن‌ها را غیرفعال کنید تا دادهٔ تکراری نداشته باشید.

## توابع PHP برای توسعه‌دهندگان

این توابع رابط عمومی و پایدار افزونه هستند و می‌توانید در قالب یا `functions.php` از آن‌ها استفاده کنید. پارامتر `$post_id` در همه اختیاری است و پیش‌فرض آن پست جاری است.

| تابع | خروجی |
|---|---|
| `omoreviews_is_enabled( $post_id )` | `bool` — آیا افزونه برای نوع این پست فعال است |
| `omoreviews_get_stats( $post_id )` | `array` — همهٔ آمار پست |
| `omoreviews_get_count( $post_id )` | `int` — تعداد نظرات تأییدشده |
| `omoreviews_get_average( $post_id )` | `float` — میانگین امتیاز |
| `omoreviews_get_criteria_average( $key, $post_id )` | `float` — میانگین یک معیار |
| `omoreviews_get_stars_html( $value, $max )` | `string` — HTML ستاره‌ها |
| `omoreviews_get_reviews_html( $post_id )` | `string` — HTML بلوک کامل نظرات |
| `omoreviews_the_reviews( $post_id )` | چاپ بلوک کامل نظرات |
| `omoreviews_get_rating_badge( $post_id, $args )` | `string` — HTML نشان امتیاز |
| `omoreviews_the_rating_badge( $post_id, $args )` | چاپ نشان امتیاز |

نمونه: نمایش امتیاز در کارت‌های آرشیو

```php
<?php if ( function_exists( 'omoreviews_the_rating_badge' ) ) : ?>
	<?php omoreviews_the_rating_badge( get_the_ID(), array( 'show_count' => false ) ); ?>
<?php endif; ?>
```

نمونه: استفاده از آمار

```php
$stats = omoreviews_get_stats( get_the_ID() );
if ( $stats['count'] > 0 ) {
	printf( 'میانگین %s از %d نظر', number_format_i18n( $stats['average'], 1 ), $stats['count'] );
}
```

## REST API و هوک‌ها

**مسیرهای REST** (namespace: `bizrev/v1`)

| مسیر | متد | کاربرد |
|---|---|---|
| `/wp-json/bizrev/v1/submit` | POST | ثبت نظر یا پاسخ |
| `/wp-json/bizrev/v1/vote` | POST | رأی مفید بود / نبود |
| `/wp-json/bizrev/v1/list` | GET | گرفتن صفحهٔ بعدی نظرات |
| `/wp-json/bizrev/v1/nonce` | GET | گرفتن nonce تازه (برای صفحات کش‌شده) |

درخواست‌های POST به nonce نیاز دارند (هدر `X-BizRev-Nonce` یا `X-WP-Nonce`). اسکریپت فرانت‌اند در صورت منقضی‌شدن nonce، آن را خودکار تازه می‌کند.

**هوک**

```php
// پس از ثبت هر نظر یا پاسخ اجرا می‌شود
add_action( 'bizrev_review_inserted', function ( $review_id, $data ) {
	// مثلاً ارسال اعلان
}, 10, 2 );
```

## پرسش‌های متداول

**کاربران مهمان هم می‌توانند نظر بدهند؟**
بله، مگر اینکه گزینهٔ «الزام ورود برای ثبت نظر» را فعال کنید.

**با کامنت‌های وردپرس تداخل دارد؟**
خیر. نظرات در جدول اختصاصی ذخیره می‌شوند و می‌توانید کامنت پیش‌فرض را روی نوع‌های فعال خاموش کنید.

**تاریخ‌ها شمسی نمایش داده می‌شوند؟**
اگر قالب یا افزونه‌ای که تابع تاریخ شمسی (مثل `jdate`) را فراهم می‌کند نصب باشد، بله. در غیر این صورت تاریخ میلادی وردپرس نمایش داده می‌شود.

**با حذف افزونه داده‌ها پاک می‌شوند؟**
با **حذف** (نه غیرفعال‌سازی) افزونه، `uninstall.php` جدول‌ها و تنظیمات را پاک می‌کند. اگر نظرات را لازم دارید، قبل از حذف از دیتابیس نسخهٔ پشتیبان بگیرید.

**صفحه کش می‌شود و ثبت نظر خطای نشست می‌دهد؟**
افزونه nonce منقضی را خودکار تازه می‌کند. اگر باز هم مشکل داشتید، مسیر `/wp-json/bizrev/v1/` را از کش افزونهٔ کش یا CDN مستثنا کنید.

## مشارکت

گزارش باگ و پیشنهاد از بخش **Issues** پذیرفته می‌شود. برای ارسال تغییرات، ریپو را fork کنید، تغییرات را در یک branch جدا انجام دهید و Pull Request بفرستید.

هنگام تغییر کد:
- مقدار `DB_VERSION` در `class-bizrev-install.php` را بدون migration تغییر ندهید.
- پیشوند `bizrev_` را برای توابع، optionها و جدول‌ها حفظ کنید.
- متن‌های نمایشی را از `BizRev_Settings::text()` بخوانید تا قابل شخصی‌سازی بمانند.

## English summary

**OmoReviews** is a multi-criteria reviews and ratings plugin for WordPress and WooCommerce, built Persian/RTL-first.

- Multi-criteria or single rating, pros and cons, "recommend" option, helpful votes, owner replies
- "Verified user" badge: automatic for WooCommerce buyers (`wc_customer_bought_product`), manual approval for any site
- Schema.org JSON-LD and Microdata (`Product`, `LocalBusiness` or `Service`) for star ratings in Google results
- 6 display templates, tabbed settings with live preview, per-post-type overrides, full text and style customization
- Shortcodes: `[omo_reviews]`, `[omo_rating]`, `[omo_average]`, `[omo_count]` (all accept `id`)
- Public PHP API (`omoreviews_*` functions), REST namespace `bizrev/v1`, action `bizrev_review_inserted`

Requires WordPress 5.8+ and PHP 7.4+. This repository is the full, open version with no license checks. Licensed under GPL-2.0-or-later.
